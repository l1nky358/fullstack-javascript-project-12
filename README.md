# Hexlet Chat

Real-time chat application built with React, Redux, and Socket.io.

## Features

- User registration and authentication
- Real-time messaging
- Channel management (create, rename, delete)
- Profanity filter
- Responsive design

## Tech Stack

- React
- Redux Toolkit
- React Router
- Socket.io
- Bootstrap
- Formik + Yup
- i18next
